# v1.41.0 — Màn Tìm gom kết quả theo tài liệu — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Màn Tìm toàn kho trả danh sách TÀI LIỆU xếp theo mật độ khớp (mỗi thẻ 1 đoạn trích + "Xem cả N đoạn" mở sheet Tìm-trong-tài-liệu điền sẵn), hết cắt theo thứ tự kho.

**Architecture:** Mỗi đơn vị trong chỉ mục mang thêm `n` (chuỗi token đã bỏ dấu) → kiểm cụm bằng `includes`, rẻ tới mức bỏ được `CANDIDATE_CAP`/`SCAN_CAP` và đếm chính xác. `searchDocs()` gom kết quả theo tài liệu, xếp BM25. UI: thẻ tài liệu ở màn Tìm, sheet trong Viewer nhận câu tra qua `?q=` và phân trang.

**Tech Stack:** Ionic React 8 + Capacitor 8, TypeScript, Vitest + Testing Library (jsdom), IndexedDB.

**Spec:** `Docs/superpowers/specs/2026-10-06-v1.41.0-search-group-by-doc-design.md` · số đo nền `Docs/perf/2026-10-06-search-lech-thu-tu-kho.md`

## Global Constraints

- Nhánh `feat/v1.41.0-search-by-doc` từ `main`; merge/tag/push CHỈ khi huynh bảo.
- Code, comment, commit message: tiếng Anh. Chuỗi trên màn hình: tiếng Việt, đúng nguyên văn trong plan.
- `n = ' ' + tokenize(text).join(' ')` — dấu cách đầu, token cách nhau đúng một dấu cách.
- `SCHEMA` (`src/search/store.ts`) = **4**. `PREFIX_CAP` = 400 GIỮ. `CANDIDATE_CAP`, `SCAN_CAP`, `phraseAt` GỠ.
- BM25 mức tài liệu: `k1 = 1.2`, `b = 0.75`, `score = count·(k1+1) / (count + k1·(1 − b + b·dl/avgdl))`; sắp `score`↓ → `count`↓ → `d`↑.
- Thứ tự đoạn (cả màn Tìm lẫn sheet): `(pos, text.length, id)` tăng dần.
- Màn Tìm: 20 thẻ/lượt, nút "Hiện thêm tài liệu". Sheet: 50 dòng/lượt, nút "Hiện thêm {k} đoạn" (k = min(50, còn lại)).
- KHÔNG đụng: `tokenize.ts`, `snippet.ts`, `docIndex.ts`, read-path PDF (`safFile.ts`), split-screen, worker, sidecar schema.
- Không đặt state đồng bộ trong `useEffect` để reset — reset bằng `key` (lint `react-hooks`).
- Mỗi task xong: `npm test` + `npm run build` + `npm run lint` xanh. Lệnh dùng ĐƯỜNG DẪN TUYỆT ĐỐI (bẫy cwd sau `cd android`).
