# v1.41.1 — Page drift, a11y, v1.41.0 leftovers — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resume never drifts pages (slide decks), every control in §1.2 of the spec is a labelled button, and the search leftovers are fixed — shipped as 1.41.1.

**Architecture:** A new pure module `src/viewer/currentPage.ts` decides the current page (most visible page + a pin that holds a jumped-to page until the user scrolls); `PdfView` only wires it in. a11y is markup-only (buttons, roles, labels). Search fixes stay inside `invertedIndex.ts` / `store.ts`; display names reach cards at render time via a `names` map returned by `refreshIndex`. The e2e suite moves to the new labels and drops the agent from the split test.

**Tech Stack:** React 19 + Ionic + Capacitor 8 (Android), react-pdf/pdf.js, vitest + @testing-library/react; e2e: tester-army/e2e 0.18 + agent-device on UBS1, `node --test` for e2e units.

**Spec:** `Docs/superpowers/specs/2026-10-09-v1.41.1-page-drift-a11y-design.md`

## Review Focus

1. **Pinch-zoomed reading, then leave and resume** — expect the same page as before leaving. Zoom re-anchors `scrollTop`, which must drop the pin. Pinned by Task 1's `pageAfterScroll` "moved > 1 px drops the pin" test; checked on device in Task 6.
2. **Mixed page heights** (a landscape table page inside a portrait document) — the footer follows the page taking the most of the screen, and resume is stable. Pinned by Task 1's mixed-heights test.
3. **Jump to the last page** (scroll clamped at the bottom, the target cannot reach the top) — footer shows the target, resume keeps it. Pinned by Task 1's clamped-pin test; checked on device in Task 6.
4. **Split view** — the top pane still saves the reading page; "Đổi" brings the picker back; exit keeps the top page. Pinned by the rewritten e2e split test (Task 5).
5. **Renamed document on the Search screen** — its card shows the new name in text and labels; a document without a rename shows its file name. Pinned by Task 3's `DocResultList` test.

**Interfaces:**

- [ ] **Step 1: Write the failing tests** in `src/viewer/currentPage.test.ts` with a helper `offs(heights: number[]): number[]` (cumulative, starts at 0):

```ts
it('a page taller than the viewport fills it → that page', () =>
  expect(mostVisiblePage(offs([1000, 1000, 1000]), 3, 1200, 600)).toBe(2));

it('two equal pages share the viewport → same page as the centre rule', () => {
  const o = offs(Array(6).fill(510)); const vh = 580;
  for (const top of [0, 37, 100, 250, 333, 600, 777, 1000, 1500, 2000]) {
    const centre = o.findIndex((y, i) => i > 0 && y > top + vh / 2);
    expect(mostVisiblePage(o, 6, top, vh)).toBe(centre);
  }
});

it('slide deck: page 3 at the top, 3 and 4 fully visible → 3 (the centre rule said 4)', () =>
  expect(mostVisiblePage(offs(Array(8).fill(276)), 8, 276 * 2, 580)).toBe(3));

it('equal visible share → the upper page', () =>
  expect(mostVisiblePage(offs([300, 300]), 2, 0, 600)).toBe(1));

it('mixed heights: 500 px of a tall page beats a fully visible 300 px page below it', () =>
  expect(mostVisiblePage(offs([800, 300, 800]), 3, 300, 800)).toBe(1));

it('one page / no pages → 1', () => {
  expect(mostVisiblePage(offs([700]), 1, 0, 580)).toBe(1);
  expect(mostVisiblePage([0], 0, 0, 580)).toBe(1);
});

it('pin holds while scrollTop stays within 1 px (bottom-clamped jump to the last page)', () =>
  expect(pageAfterScroll({ page: 8, top: 1628 }, 1628.5, 7)).toEqual({ page: 8, pin: { page: 8, top: 1628 } }));

it('a move of more than 1 px (user scroll, zoom re-anchor) drops the pin', () =>
  expect(pageAfterScroll({ page: 8, top: 1628 }, 1640, 7)).toEqual({ page: 7, pin: null }));

it('no pin → the visible page', () =>
  expect(pageAfterScroll(null, 500, 4)).toEqual({ page: 4, pin: null }));
```

(Tops in the centre-rule test avoid exact ties, where the centre rule picks the lower page and ours the upper.)

- [ ] **Step 2: Run** `npx vitest run src/viewer/currentPage.test.ts` — Expected: FAIL (module not found).

- [ ] **Step 3: Implement `src/viewer/currentPage.ts`.** `mostVisiblePage`: for each page n intersecting `[top, top + vh)`, visible = `min(offsets[n], top + vh) − max(offsets[n − 1], top)`; return the n with the largest visible height, ties → smaller n; nothing visible or `numPages === 0` → 1 (visible **pixels**, spec §4.1 as amended 10/10). `pageAfterScroll`: pin kept iff `pin && Math.abs(scrollTop − pin.top) <= 1`, then `page = pin.page`; otherwise `{ page: visible, pin: null }`.

In `recompute`, replace the `pageAtY(…, top + vh / 2)` line: `const r = pageAfterScroll(pin.current, top, mostVisiblePage(offsets, numPages, top, vh)); pin.current = r.pin;` and report `r.page`.
