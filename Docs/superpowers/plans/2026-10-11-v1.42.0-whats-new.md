# v1.42.0 — "Có gì mới" — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After each update the app shows Pé, once, what changed in the versions she has not seen yet (at most 3); Settings shows the 3 latest on demand; a test makes a release without notes impossible.

**Architecture:** Hand-written notes in `src/whatsNew/notes.ts`; pure selection in `src/whatsNew/select.ts`; the last seen version in Capacitor Preferences (`src/whatsNew/seen.ts`); one sheet component (`WhatsNewSheet`) used by an App-level one-shot notice (`WhatsNewNotice`, like `CrashNotice`) and by a Settings entry (`WhatsNewEntry`). The e2e `toTab` dismisses the sheet on the first run after an install.

**Tech Stack:** React 19 + Ionic + Capacitor 8 (`@capacitor/preferences`), vitest + @testing-library/react (jsdom; `__APP_VERSION__` defined from package.json in `vite.config.ts`); e2e: tester-army/e2e on UBS1.

**Spec:** `Docs/superpowers/specs/2026-10-11-v1.42.0-whats-new-design.md`

## Global Constraints

- Version **1.42.0**. No index `SCHEMA` change, no reading-state change.
- Code, comments, commit messages in English; every user-facing string in Vietnamese exactly as below.
- UI copy: sheet title `Có gì mới` · header close `Đóng` (GuSheet default) · bottom button `Đã hiểu` · version heading `Phiên bản {version} · {date}` · kind chips `Mới` / `Sửa lỗi` / `Cải thiện` · Settings entry text `Có gì mới · Phiên bản {version}` with aria-label `Xem có gì mới, phiên bản {version}`.
- Chip colors (B1 row palette): `Mới` → `var(--gu-brown)`, `Sửa lỗi` → `var(--ion-color-danger)`, `Cải thiện` → `#4A5D3A`; white text.
- Preferences key: `whats_new_seen`.
- Notes text = spec §5 verbatim (huynh-approved), in huynh's voice to Pé: never the word "Gú", no code words.
- Device rules: never install test builds on Gú's phone; dGen1 never `am force-stop` (`adb install -r`, launch via `monkey`/launcher).
- Commands: `npx vitest run` · `npm run build` · lint: no new problems vs main (main already has 23) · `npm --prefix e2e run unit` · `npm --prefix e2e run typecheck` · `npm run e2e`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Preferences cannot be read** (storage error) — the app must start normally and show nothing rather than crash or nag every launch. Pinned by Task 4's "get rejects → no sheet" test.
2. **Closing the sheet any other way** (header "Đóng", swipe down, Android back) — counts as seen; it must not come back next launch. Pinned by Task 4's "Đóng also records seen" test; Android back checked on device in Task 7.
3. **Downgrade or reinstall of the same version** — no sheet. Pinned by Task 1's `seen ≥ current → []` tests.
4. **The first e2e run right after installing a new APK** — the sheet covers Home in the first test; the suite must still pass. Pinned by Task 6's `toTab` change, proven in Task 7 by running `npm run e2e` immediately after install.
5. **Long notes on the square dGen1 screen** — the sheet scrolls and "Đã hiểu" stays reachable. Checked on device in Task 7.

### Task 1: Version selection (pure)

**Files:**
- Create: `src/whatsNew/select.ts`, `src/whatsNew/select.test.ts`, `src/whatsNew/types.ts`

**Interfaces:**
- Produces (`types.ts`): `export type NoteKind = 'new' | 'fix' | 'improve'` · `export interface ReleaseNote { version: string; date: string; items: { kind: NoteKind; text: string }[] }`
- Produces (`select.ts`): `compareVersions(a: string, b: string): number` · `unseenNotes(notes: ReleaseNote[], lastSeen: string | null, current: string, max = 3): ReleaseNote[]` · `recentNotes(notes: ReleaseNote[], current: string, max = 3): ReleaseNote[]`

- [ ] **Step 1: Write the failing tests** (`select.test.ts`), with `const N = (v: string): ReleaseNote => ({ version: v, date: '01/01/2026', items: [{ kind: 'fix', text: 'x' }] })` and `const NOTES = ['1.42.0', '1.41.1', '1.41.0', '1.40.1'].map(N)`; `const vs = (ns: ReleaseNote[]) => ns.map((n) => n.version)`:

```ts
it('compares by number, not text', () => {
  expect(compareVersions('1.10.0', '1.9.0')).toBeGreaterThan(0);
  expect(compareVersions('1.41.1', '1.41.0')).toBeGreaterThan(0);
  expect(compareVersions('1.41.0', '1.41.0')).toBe(0);
  expect(compareVersions('1.41', '1.41.0')).toBe(0);           // a missing part counts as 0
  expect(compareVersions('1.42.0-debug', '1.42.0')).toBe(0);   // a non-numeric tail is ignored
});
it('skipped versions all show, newest first', () =>
  expect(vs(unseenNotes(NOTES, '1.40.1', '1.42.0'))).toEqual(['1.42.0', '1.41.1', '1.41.0']));
it('at most 3', () =>
  expect(vs(unseenNotes(NOTES, '1.39.0', '1.42.0'))).toEqual(['1.42.0', '1.41.1', '1.41.0']));
it('never seen anything → only the current version', () =>
  expect(vs(unseenNotes(NOTES, null, '1.42.0'))).toEqual(['1.42.0']));
it('already seen, reinstall or downgrade → nothing', () => {
  expect(unseenNotes(NOTES, '1.42.0', '1.42.0')).toEqual([]);
  expect(unseenNotes(NOTES, '1.43.0', '1.42.0')).toEqual([]);
});
it('versions newer than the running app never show', () =>
  expect(vs(unseenNotes(NOTES, '1.41.0', '1.41.1'))).toEqual(['1.41.1']));
it('running version without a note → nothing, no error', () =>
  expect(unseenNotes(NOTES, null, '1.43.0')).toEqual([]));
it('recentNotes: the 3 latest up to the running version', () =>
  expect(vs(recentNotes(NOTES, '1.41.1'))).toEqual(['1.41.1', '1.41.0', '1.40.1']));
```

- [ ] **Step 1: Write the failing tests** (`notes.test.ts`):

```ts
it('the version being built has notes (a release cannot forget them)', () =>
  expect(RELEASE_NOTES[0].version).toBe(__APP_VERSION__));
it('newest first, no duplicates', () => {
  for (let i = 0; i + 1 < RELEASE_NOTES.length; i++)
    expect(compareVersions(RELEASE_NOTES[i].version, RELEASE_NOTES[i + 1].version)).toBeGreaterThan(0);
});
it('every version has at least one line and a dd/mm/yyyy date', () => {
  for (const n of RELEASE_NOTES) {
    expect(n.items.length).toBeGreaterThan(0);
    expect(n.date).toMatch(/^\d{2}\/\d{2}\/\d{4}$/);
  }
});
it('plain words for Pé: no code words, never "Gú"', () => {
  for (const { text } of RELEASE_NOTES.flatMap((n) => n.items)) {
    expect(text).not.toMatch(/`/);
    expect(text).not.toMatch(/[a-z][A-Z]/);
    expect(text).not.toMatch(/\.(tsx?|json)\b/);
    expect(text).not.toMatch(/Gú/);
  }
});
```
