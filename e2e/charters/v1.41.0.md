# Đề bài khám phá — v1.41.0 (tìm kiếm gom theo tài liệu)

Chạy từng đề trên UBS1 (kho QA), mỗi đề một lệnh:

```bash
npm --prefix e2e run explore -- "<đề bài>"
```

Agent `explorer` chỉ đọc; `scripts/explore.ts` so dấu vân tay kho trước/sau và báo
**VI PHẠM CHỈ-ĐỌC** nếu kho đổi.

## 1. Sinh viên lần đầu dùng app

**Vai:** sinh viên luật, lần đầu mở app, chưa biết các nút.

> Dùng tìm kiếm và nút 'Xem cả N đoạn' như một sinh viên luật lần đầu dùng app; báo chỗ khó hiểu, số không khớp, hoặc bấm mà không có phản hồi.

## 2. Người gõ dở, đổi ý

**Vai:** người gõ dở rồi đổi ý, chuyển qua lại liên tục.

> Gõ dở rồi đổi câu tra, xoá câu tra, chuyển qua lại giữa tab Tìm và Trang chủ, mở rồi đóng tài liệu; tìm trạng thái sai hoặc kẹt.
